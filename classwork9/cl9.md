========================
ЗАДАЧИ ПО GO — JSON ФАЙЛЫ
========================

1. Сохранение пользователя в JSON

Создай структуру:

type User struct {
    Name string
    Age  int
}

Пользователь вводит имя и возраст.
Нужно сохранить данные в user.json.


-----------------------------------

2. Чтение JSON файла

Есть файл:

{
  "name": "Ali",
  "age": 18
}

Нужно прочитать файл и вывести:

Name: Ali
Age: 18


-----------------------------------

3. Список студентов

Создай структуру:

type Student struct {
    Name  string
    Grade int
}

Нужно:
- добавить 3 студентов
- сохранить их в students.json

Пример JSON:

[
  {
    "name": "Ali",
    "grade": 90
  },
  {
    "name": "Umed",
    "grade": 85
  }
]


-----------------------------------

4. Подсчёт среднего балла

Прочитай students.json и найди средний балл всех студентов.


-----------------------------------

5. Поиск студента

Пользователь вводит имя.
Нужно найти студента в JSON файле.

Вывод:

Found: Ali - 90

или

Student not found


-----------------------------------

6. Добавление нового студента

Программа должна:
- прочитать students.json
- добавить нового студента
- сохранить файл обратно


-----------------------------------

7. Удаление студента

Пользователь вводит имя студента.
Нужно удалить его из JSON файла.


-----------------------------------

8. Сортировка студентов

Отсортируй студентов:
- по имени
или
- по баллу

И сохрани обратно в JSON.


-----------------------------------

9. Мини-база товаров

Структура:

type Product struct {
    Name     string
    Price    float64
    Quantity int
}

Нужно:
- добавить товары
- сохранить в products.json
- посчитать общую стоимость всех товаров


-----------------------------------

10. Самый дорогой товар

Из JSON файла нужно найти товар с самой большой ценой.

Данные использовать из 9 задачи
-----------------------------------

11. Мини-система заказов

Структура:

type Order struct {
    ID       int
    Customer string
    Total    float64
}

Нужно:
- сохранить несколько заказов
- вывести все заказы
- найти заказ с максимальной суммой


-----------------------------------

12. JSON + статистика

Есть JSON файл с пользователями:

[
  {
    "name": "Ali",
    "age": 18
  },
  {
    "name": "John",
    "age": 25
  }
]

Найти:
- самого старшего пользователя
- самого младшего
- средний возраст


-----------------------------------
