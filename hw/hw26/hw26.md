# Домашняя работа: Аналитика интернет-магазина (SQL)
## 1. Схема базы данных

Ниже представлены структуры таблиц, которые используются в заданиях. При проектировании таких структур для микросервисов рекомендуется использовать формат **JSON** для обмена данными между компонентами.

### Таблица `customers` (Клиенты)
*   `id` — уникальный идентификатор.
*   `full_name` — имя клиента.
*   `city` — город.

### Таблица `products` (Товары)
*   `id` — уникальный идентификатор.
*   `title` — название.
*   `price` — цена.

### Таблица `orders` (Заказы)
*   `id` — номер заказа.
*   `customer_id` — связь с клиентом.
*   `product_id` — связь с товаром.
*   `quantity` — количество.
*   `created_at` — дата создания.

## 2. Практические задания

### Базовые выборки и фильтрация
*   **Задание 1.** Выведите список всех заказов. Результат должен содержать: ID заказа, имя клиента, название товара и количество.
*   **Задание 2.** Выведите все заказы клиентов из города "Dushanbe".
*   **Задание 3.** Выведите все товары дороже 500, отсортировав их по цене (по убыванию).

### Агрегация данных (COUNT, SUM, AVG)
*   **Задание 4.** Найдите количество заказов для каждого клиента (имя клиента, кол-во заказов).
*   **Задание 5.** Найдите количество продаж каждого товара (название товара, кол-во заказов).
*   **Задание 6.** Найдите общую сумму каждого заказа (подсказка: `quantity * price`). Результат: ID заказа, клиент, товар, итоговая сумма.
*   **Задание 7.** Найдите общую сумму покупок для каждого клиента (клиент, общая сумма потраченных денег).

### Работа с условиями и функциями
*   **Задание 8.** Выведите список клиентов, которые совершили более одного заказа.
*   **Задание 9.** Найдите самый дорогой товар в базе данных, используя функцию `MAX()`.
*   **Задание 10.** Найдите среднюю стоимость всех товаров в магазине, используя функцию `AVG()`.

### Аналитика и ТОП-рейтинги
*   **Задание 11.** Найдите клиента, который совершил больше всего заказов (используйте `COUNT()`, `ORDER BY` и `LIMIT`).
*   **Задание 12.** Выведите ТОП-5 клиентов по общей сумме их покупок.
*   **Задание 13.** Выведите список товаров, которые были заказаны более одного раза (используйте `GROUP BY` и `COUNT()`).
*   **Задание 14.** Найдите самый продаваемый товар (по суммарному количеству проданных единиц).
*   **Задание 15 ⭐.** Сформируйте итоговый отчёт по клиентам. Для каждого клиента выведите:
    *   имя клиента;
    *   общее количество заказов;
    *   общую сумму покупок;
    *   средний чек.
    *   *Сортировка:* по общей сумме покупок от большего к меньшему.
