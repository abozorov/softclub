# 📚 Задания по изучению Go: Модули и Пакеты

## 🟦 Задание 1. Интернет-магазин (`shop`)

**Цель:** Научиться разделять логику приложения на разные пакеты и работать со срезами структур.

### 📁 Структура проекта
```text
shop/
├── go.mod
├── main.go
├── products/
│   └── products.go
└── utils/
    └── utils.go
```

### 🧠 Содержимое пакетов

#### 1. `products/products.go`
Создайте структуру и функции для обработки данных:
*   **Структура `Product`**:
    *   `Name` (string)
    *   `Price` (float64)
    *   `Quantity` (int)
*   **Функция `TotalPrice(products []Product) float64`**: считает общую стоимость всех товаров (`Price * Quantity`).
*   **Функция `MostExpensive(products []Product) Product`**: находит и возвращает товар с самой высокой ценой.

#### 2. `utils/utils.go`
Создайте вспомогательную функцию для вывода:
*   **Функция `PrintProduct(p products.Product)`**: красиво выводит данные о товаре в консоль.
    *   *Пример вывода:*
        ```text
        Название: iPhone
        Цена: 1200
        Количество: 2
        ```

### 🚀 Задание для `main.go`
В главном файле необходимо:
1. Создать срез (slice) из нескольких товаров.
2. Вызвать функцию `TotalPrice` и вывести результат.
3. Найти самый дорогой товар через `MostExpensive`.
4. Вывести данные этого товара в консоль, используя `PrintProduct`.

## 🟨 Задание 2. JSON + пользователи (`jsonapp`)

**Цель:** Изучить работу с форматом JSON, который является стандартом для обмена данными в современных Web API.

### 📁 Структура проекта
```text
jsonapp/
├── go.mod
├── main.go
├── models/
│   └── user.go
└── storage/
    └── storage.go
```

### 🧠 Содержимое пакетов

#### 1. `models/user.go`
Определите структуру данных с JSON-тегами:
*   **Структура `User`**:
    *   `Name` (с тегом `json:"name"`)
    *   `Age` (с тегом `json:"age"`)

#### 2. `storage/storage.go`
Реализуйте логику сохранения данных (имитация работы с базой данных или файловым хранилищем):
*   **Функция `SaveUsers(users []models.User)`**:
    1. Преобразует список пользователей в формат JSON.
    2. Сохраняет полученный результат в файл `users.json`.
*   **Функция `LoadUsers() []models.User`**:
    1. Читает данные из файла `users.json`.
    2. Декодирует JSON обратно в срез структур `User` и возвращает его.

### 🚀 Задание для `main.go`
В главном файле необходимо:
1. Создать список (срез) из нескольких пользователей.
2. Сохранить их в файл, используя пакет `storage`.
3. Загрузить данные из этого же файла в новую переменную.
4. Вывести загруженный список пользователей в консоль для проверки.
