# 🧩 Задача 1 — Система уведомлений

## 📌 Описание
Создайте систему отправки уведомлений пользователям.

## 📌 Структура

```go
type Notification struct {
	User    string
	Message string
}
```

## 📌 Интерфейс

```go
type Sender interface {
	Send(n Notification) error
}
```

## 📌 Реализовать

```go
type EmailSender struct{}
type SmsSender struct{}
```

## 📌 Условия

### EmailSender
- сообщение не может быть пустым
- выводит:

```text
Email sent to Ali
```

### SmsSender
- длина сообщения должна быть <= 50 символов
- если больше → ошибка

## 📌 Реализовать функцию

```go
func SendAll(senders []Sender, n Notification) []error
```

## 📌 Что должна делать функция
- пройтись по всем sender
- вызвать Send()
- если ошибка → добавить в []error

## 📌 Дополнительно
Сохранить успешные уведомления в файл:

```text
notifications.txt
```

## 📌 Использовать
- interface
- struct
- slice
- errors
- files
- strings

# 🧩 Задача 2 — Анализ товаров магазина

## 📌 Структура

```go
type Product struct {
	Name     string
	Category string
	Price    float64
	Quantity int
}
```

## 📌 Реализовать функции

### 1. Общая стоимость товаров

```go
func TotalPrice(products []Product) float64
```

📌 Условие:
Посчитать:

```text
Price * Quantity
```

для всех товаров.

### 2. Самый дорогой товар

```go
func MostExpensive(products []Product) Product
```

📌 Условие:
Вернуть товар с самой большой ценой.

### 3. Статистика категорий

```go
func CategoryStats(products []Product) map[string]int
```

📌 Условие:
Посчитать:
- сколько товаров в каждой категории

## 📌 Дополнительно
Сохранить статистику в файл:

```text
stats.txt
```

## 📌 Использовать
- struct
- slice
- map
- files
- функции
- бизнес-логику
