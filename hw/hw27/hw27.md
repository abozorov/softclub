## 🔍 Задача 1. Поиск пропущенного числа
Дан массив чисел от **1** до **N**. Одно число в массиве отсутствует. Необходимо найти отсутствующее число.

**Пример:**
*   **Вход:** `[1, 2, 3, 5]`
*   **Выход:** `4`

## 🔠 Задача 2. Первый уникальный символ
Дана строка. Необходимо найти первый символ, который встречается в строке только один раз. Если такого символа нет, вернуть ошибку или специальное значение.

**Пример:**
*   **Вход:** `swiss`
*   **Выход:** `w`

## 🔄 Задача 3. Проверка анаграммы
Даны две строки. Необходимо определить, являются ли они анаграммами. Анаграммы содержат одинаковые символы в одинаковом количестве.

**Пример 1:**
*   **Вход:** `listen`, `silent`
*   **Выход:** `true`

**Пример 2:**
*   **Вход:** `hello`, `world`
*   **Выход:** `false`

## 🤐 Задача 4. Сжатие строки
Реализуйте простейший алгоритм сжатия строки. Последовательные одинаковые символы должны заменяться на символ и количество его повторений подряд.

**Пример 1:**
*   **Вход:** `aaabbcccc`
*   **Выход:** `a3b2c4`

**Пример 2:**

*   **Выход:** `a1b1c1d1`

## 👥 Задача 5. Поиск повторяющихся пользователей
В системе зарегистрированы пользователи. Каждый пользователь должен входить в систему только один раз. Дан массив идентификаторов пользователей. Необходимо найти пользователей, которые встречаются более одного раза. Если таких несколько, вернуть всех.

**Пример 1:**
*   **Вход:** `[1, 2, 3, 4, 2, 5]`
*   **Выход:** `[2]`

**Пример 2:**
*   **Вход:** `[1, 2, 3, 2, 1, 4]`
*   **Выход:** `[1, 2]`

## 💡 Задача 6. Лампочки
Есть **100** лампочек. Изначально все они выключены.
1. На первом проходе переключаются все лампочки.
2. На втором проходе переключается каждая вторая лампочка.
3. На третьем проходе переключается каждая третья лампочка.
4. Процесс продолжается до сотого прохода.

**Необходимо:**
*   Определить, какие лампочки останутся включёнными.
*   Написать программу, которая вычисляет результат для любого количества лампочек.

**Пример для 10 лампочек:**
*   **Выход:** `1 4 9`

**Пример для 30 лампочек:**
*   **Выход:** `1 4 9 16 25`

## 🛗 Задача 7. Лифт
Лифт находится на **0** этаже. Дан список команд: `[]int{3, -2, 5, -1}`.
*   *Положительное число* — подъём на указанное количество этажей.
*   *Отрицательное число* — спуск на указанное количество этажей.

**Необходимо найти:**
1. Конечный этаж.
2. Максимальный этаж, на котором находился лифт.
3. Минимальный этаж, на котором находился лифт.

**Пример:**
*   **Вход:** `[]int{3, -2, 5, -1}`
*   **Выход:**
    *   Конечный этаж: **5**
    *   Максимальный этаж: **6**
    *   Минимальный этаж: **0**
