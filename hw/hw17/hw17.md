# 🔷 Задача 1 — Система управления библиотекой

## 📌 Описание

Создайте систему для управления библиотекой.

---

## 📌 Структура книги:

```go id="a2z8wu"
type Book struct {
	ID        int
	Title     string
	Author    string
	Pages     int
	Available bool
	CreatedAt time.Time
}
```

---

## 📌 Интерфейс:

```go id="x4d8tr"
type BookManager interface {
	AddBook(book Book) error
	TakeBook(id int) error
	ReturnBook(id int) error
	ShowBooks()
}
```

---

## 📌 Программа должна уметь:

✅ Добавлять книгу

📌 Ошибки:

* ID не может быть <= 0
* название пустое
* количество страниц <= 0

---

✅ Брать книгу

📌 Условия:

* если книга уже занята → ошибка
* если книга не найдена → ошибка
* если всё успешно:

  * `Available = false`

---

✅ Возвращать книгу

📌 Условия:

* если книги нет → ошибка
* если книга уже свободна → ошибка

---

✅ Показывать:

* все книги
* только свободные книги
* только занятые книги

---

✅ Найти:

* книгу с самым большим количеством страниц
* автора с самым большим количеством книг

---

✅ Посчитать:

* сколько свободных книг
* сколько занятых

---

✅ Сохранить библиотеку в файл:

```text id="f67h8x"
library.txt
```

---

## 📌 Использовать:

* interface
* struct
* methods
* slice
* map
* files
* errors
* time.Now()
* business logic

# 🔶 Задача 2 — Анализ интернет-магазина

## 📌 Есть файл:

```text id="rq0m1g"
orders.txt
```

---

## 📌 Пример содержимого:

```text id="pj9h0w"
Ali Phone 1200 success
Vali Mouse 200 failed
Ali Keyboard 500 success
Sami Phone 1200 success
Ali Mouse 200 success
```

---

## 📌 Структура:

```go id="0d9csh"
type Order struct {
	User    string
	Product string
	Price   float64
	Status  string
}
```

---

## 📌 Нужно:

✅ Прочитать файл

✅ Сохранить данные в slice структур

---

## 📌 Посчитать:

* сколько успешных заказов
* сколько неуспешных
* общую сумму успешных заказов
* сколько заказов у каждого пользователя
* сколько раз покупался каждый товар

---

## 📌 Найти:

* самого активного покупателя
* самый популярный товар
* пользователя, который потратил больше всего денег
