=========================================
1. Генератор чисел с остановкой
=========================================

Создай функцию:

func generator(ctx context.Context, numbers chan int)

Она должна:
- каждую секунду отправлять в канал число:
  1, 2, 3, 4 ...
- если контекст завершён:
  вывести:
  Генератор остановлен
- закрыть канал.

В main:
- создай context.WithCancel
- запусти generator в goroutine
- считай числа через range
- после получения 5 чисел вызови cancel()
- завершай программу корректно


=========================================
2. Ограничение времени обработки заказа
=========================================

Создай функцию:

func processOrder(ctx context.Context)

Логика:
- обработка заказа занимает 6 секунд
- каждую секунду выводить:

  Обрабатывается заказ...

- если время вышло:
  вывести:

  Заказ отменён

- если успела закончить:
  вывести:

  Заказ выполнен

В main:
- создать context.WithTimeout на 4 секунды
- вызвать функцию


=========================================
3. Передача значения через context
=========================================

Создай структуру:

type User struct {
    Name string
}

Создай функцию:

func printUser(ctx context.Context)

Она должна:
- получить пользователя из context
- вывести:

  Пользователь: <имя>

Если значения нет:
- вывести:

  Пользователь не найден

В main:
- создать context.WithValue
- передать пользователя
- вызвать функцию


=========================================
4. Конкурирующие задачи (кто успеет первым)
=========================================

Запусти 3 goroutine.

Каждая:
- ждёт разное время:
  2 сек
  4 сек
  6 сек
- после ожидания пишет:

  Worker X завершился

Требования:
- использовать один общий context.WithCancel
- как только один завершился —
  остальные должны остановиться
- остановленные выводят:

  Worker X отменён


=========================================
5. Цепочка вызовов с context
=========================================

Создай функции:

func service(ctx context.Context)
func repository(ctx context.Context)

Логика:
- main вызывает service
- service вызывает repository
- repository работает 7 секунд
- каждую секунду проверяет контекст

Требования:
- создать timeout на 5 секунд
- если время вышло:
  repository выводит:

  Репозиторий остановлен

- service выводит:

  Операция не завершена

- если всё успело —
  вывести успешное сообщение
