=========================================
1. Очередь заказов
=========================================

Создай канал orders.

Горутина должна отправить в него заказы:

Заказ #101
Заказ #102
Заказ #103
Заказ #104

После отправки закрыть канал.

В main обработай все заказы через:

for order := range orders

и выведи:

Обрабатывается: Заказ #...


=========================================
2. Фильтрация данных
=========================================

Есть числа:

3 8 15 20 27 40

Горутина получает числа и отправляет в канал
только значения больше 10.

Главная goroutine получает и выводит результат.

Ожидаемый вывод:

15
20
27
40


=========================================
3. Онлайн-магазин
=========================================

Создай два канала:

products
prices

Одна goroutine отправляет:

Phone
Laptop
Tablet

Вторая отправляет:

1000
2500
800

В main получай данные из обоих каналов
и выводи:

Phone - 1000
Laptop - 2500
Tablet - 800

Подумай как сделать так,
чтобы данные не перепутались.


=========================================
4. Кто закончит раньше (select)
=========================================

Создай два канала.

Первая goroutine имитирует загрузку файла
(ждёт 2 секунды).

Вторая имитирует получение данных
(ждёт 1 секунду).

Используй select и выведи только то сообщение,
которое пришло первым.

Пример:

Download completed


=========================================
5. Мониторинг сервера (select)
=========================================

Создай два канала:

errors
success

Одна goroutine отправляет:

Server Error

Вторая отправляет:

Request Success

В main используй цикл + select.

Программа должна дождаться первого сообщения,
вывести его и завершиться.

Пример вывода:

Успех: Request Success

или

Ошибка: Server Error
