
# 🎓 Экзаменационные задачи по программированию на Go

## 📝 Задача №1. Работа с JSON файлами
**Тема:** Система управления студентами

Данное задание направлено на отработку навыков сериализации и десериализации данных. Формат **JSON** является общепринятым стандартом в Web API благодаря своей легкости и читаемости.

### 🛠 Требования:
1.  **Создать структуру `Student`** со следующими полями:
    *   `ID` (int)
    *   `Name` (string)
    *   `Age` (int)
    *   `Grade` (float64)
    *   `Passed` (bool)

2.  **Реализовать функционал программы:**
    *   **Чтение:** Считать данные из файла `students.json`.
    *   **Декодирование:** Преобразовать JSON-данные в срез структур (slice).
    *   **Аналитика:** Вывести в консоль:
        *   Общее количество студентов.
        *   Средний балл (`Grade`) всех учеников.
        *   Список имен студентов, успешно сдавших экзамен (`Passed == true`).
    *   **Обновление:** Добавить в список нового студента программно.
    *   **Сохранение:** Записать обновленный список обратно в файл `students.json`.

### 📄 Пример входного файла (`students.json`):
```json
[
  {
    "id": 1,
    "name": "Ali",
    "age": 19,
    "grade": 88.5,
    "passed": true
  },
  {
    "id": 2,
    "name": "Umed",
    "age": 20,
    "grade": 56.2,
    "passed": false
  }
]
```

## 📦 Задача №2. Пакеты и модули
**Тема:** Архитектура интернет-магазина

Цель задачи — научиться разделять код на независимые модули. Подобная модульность лежит в основе **API**, где каждая часть системы взаимодействует с другой через четко определенные границы (интерфейсы).

### 📁 Структура проекта (`shop/`)
```text
shop/
├── go.mod              # Файл инициализации модуля
├── main.go            # Точка входа в программу
├── models/
│   └── product.go     # Описание сущностей
├── services/
│   └── calculator.go  # Бизнес-логика расчетных функций
└── storage/
    └── storage.go     # Имитация хранилища данных
```

### 🧠 Требования к пакетам:

#### 1. Пакет `models`
Определите структуру товара. В программировании ресурсы (например, товары) часто описываются через классы или структуры:
*   **Структура `Product`**: `ID`, `Name`, `Price`, `Quantity`.

#### 2. Пакет `services`
Реализуйте логические функции:
*   `TotalPrice(products []models.Product) float64`: возвращает суммарную стоимость всех позиций.
*   `MostExpensive(products []models.Product) models.Product`: возвращает товар с максимальной ценой.

#### 3. Пакет `storage`
Создайте функцию для наполнения данными:
*   `SeedProducts() []models.Product`: должна возвращать готовый список (минимум 5 товаров).

#### 4. Файл `main.go`
Основной алгоритм работы:
1.  Инициализировать модуль через `go mod init shop`.
2.  Получить список товаров из пакета `storage`.
3.  Вывести список всех доступных товаров.
4.  Вызвать сервисные функции и напечатать:
    *   **Общую стоимость** всего склада.
    *   Подробную информацию о **самом дорогом товаре**.
