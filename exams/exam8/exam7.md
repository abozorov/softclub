ЗАДАЧА ПО GO (ИНТЕРФЕЙСЫ)

Тема: Система оплаты заказов

Создайте интерфейс:

type PaymentProcessor interface {
    Process(amount float64) error
}

Реализуйте две структуры:

type CardPayment struct{}

type CashPayment struct{}

Каждая структура должна реализовать метод:

Process(amount float64) error

Логика:

- Если сумма меньше или равна 0, необходимо вернуть ошибку.
- Для успешной оплаты вывести сообщение:
    Оплата картой: 100.50
    Оплата наличными: 100.50

Создайте функцию:

func Pay(p PaymentProcessor, amount float64) error

которая принимает любой способ оплаты и вызывает его метод Process.

В функции main():

1. Выполнить оплату картой на сумму 100.
2. Выполнить оплату наличными на сумму 50.
3. Попробовать выполнить оплату на сумму -10.
4. Корректно обработать возникшую ошибку.

Требования:

- Использовать интерфейс.
- Реализовать интерфейс двумя разными структурами.
- Использовать полиморфизм через функцию Pay.
- Реализовать обработку ошибок.
- Продемонстрировать работу программы в main().
